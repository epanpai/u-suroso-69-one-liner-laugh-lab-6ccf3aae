## The entry

> The sock and I eloped. We're very happy, and the dryer will never find us.

74 characters, one line, one everyday truth: the vacuum didn't eat the sock — it ran away with it, and the dryer (the household's other famous sock-eater) will never find them.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed line to `/output/entry.txt` — 74 characters, inside the 1–200 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
